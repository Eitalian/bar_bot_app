# Визуальный дизайн Telegram-меню

> **Назначение:** справочник скринов бота для быстрого просмотра без нажатия кнопок.
>
> **Обновление:** обязательно при любом изменении текста сообщений, набора кнопок или порядка шагов Conversation. Пункт добавляется в секцию **Steps** финальной задачи каждого плана, затрагивающего Telegram-UI.
>
> **Источник правды:** `app/Actions/`, `app/Telegram/Conversations/`, `app/Telegram/Responses/`.

---

## Обозначения

```
[Текст кнопки]          — InlineKeyboardButton в одну строку (одна кнопка на ряд)
[Кнопка А] [Кнопка Б]  — два и более InlineKeyboardButton в одном ряду
[Кнопка А]
[Кнопка Б]             — две кнопки в разных рядах

💬 текст                — sendMessage / editMessageText (основное сообщение)
🔔 условие             — кнопка или текст отображается только при выполнении условия
📝 ввод текста         — бот ждёт текстового ввода от пользователя
→                      — переход к следующему экрану / следующему шагу
```

## 2. Инвентарь

**Триггер:** `/inventory`, callback `inventory:show`  
**Action:** `InventoryAction::fromTelegram`

### 2a. Инвентарь не пуст

```
💬 📦 *Инвентарь бара* — {N} позиций:

[Водка — 500 мл]                  [❌]
```

> Каждый ингредиент — строка из двух кнопок: label с количеством (noop) + ❌ с `inventory:remove:{id}`.


## 3. Добавить ингредиент (Conversation)

**Триггер:** callback `inventory:add` (только bartender/owner)  
**Conversation:** `AddInventoryConversation`

### Шаг 1 — поиск

```
💬 🔍 Введите название ингредиента:

📝 [ждёт текстового ввода]
```

### Шаг 2a — ничего не найдено

```
💬 😔 Ничего не найдено по «{query}». Попробуйте ещё раз:

📝 [ждёт текстового ввода]
```

### Шаг 2b — найдены ингредиенты

```
💬 Выберите ингредиент:

[Водка]
[Водка клюквенная]
[Водка лимонная]
...до 8 штук
```

> Callback_data каждой кнопки: `inventory:select:{ingredient.id}`.

### Шаг 3 — ввод количества

```
💬 Введите количество (например: 500 мл, 2 бутылки)
или нажмите Пропустить:

[Пропустить]

📝 [ждёт текстового ввода или нажатия Пропустить]
```

### Шаг 4 — результат

> После сохранения — `AddInventoryAction::fromTelegram` показывает обновлённый инвентарь (экран 2).

## 5. Поиск по ингредиентам (Conversation)

**Триггер:** callback `cmd:ingredients`  
**Conversation:** `SearchByIngredientConversation`

### Шаг 1 — инструкция

```
💬 🧪 *Поиск по ингредиентам*

Введите название ингредиента (на русском или английском, например: `водка`, `bourbon`, `lime juice`).

Можно добавить несколько — бот найдёт коктейли, в которых *все* они есть.

Чтобы начать поиск, напишите /done

📝 [ждёт текстового ввода]
```

### Шаг 2a — ингредиент найден (единственный)

```
💬 ✅ Добавлен: *{ingredient.id}*

Текущий список: `vodka, lime-juice`

Добавьте ещё или напишите /done

📝 [ждёт текстового ввода]
```

### Шаг 2b — несколько совпадений, уточнение

```
💬 Уточните ингредиент:

[vodka (Водка)]
[vodka-cranberry (Водка клюквенная)]
...до 5 штук

📝 [ждёт выбора кнопки или нового ввода]
```

### Шаг 2c — ингредиент не найден

```
💬 ❌ Ингредиент *"{text}"* не найден. Попробуйте другое название.

📝 [ждёт текстового ввода]
```

### Шаг 3 — /done → результаты

> Передаёт управление `SearchByIngredientAction` → экран **6. Результаты поиска**.

## 9a. Карточка рецепта (Phase 4 — кнопки подробно)

Ряды кнопок снизу карточки (добавлены в Phase 4):

```
Ряд «избранное» (всегда):
  [❤️ Убрать из избранного]   — если recipe уже в избранном у пользователя
  [🤍 В избранное]            — если recipe НЕ в избранном

Ряд «оценка»:
  [⭐1][⭐2][⭐3][⭐4][⭐5]   — если пользователь ещё не оценивал
  [Переоценить (3⭐)]         — если пользователь уже поставил оценку (показывается текущий балл)
```

## 10. Заказ коктейля

**Триггер:** callback `recipe:order:{id}` (только при активной сессии)  
**Action:** `PlaceOrderAction::fromTelegram`

### Шаг 1 — выбор количества

```
💬 {текущая карточка рецепта — editMessageReplyMarkup}
    (текст остаётся, меняется только клавиатура)

[1] [2] [3] [4] [5]
[🔙 Назад]
```

> Toast-уведомление: «Выбери количество»

### Шаг 2 — после выбора количества

**Триггер:** callback `recipe:order:{id}:{qty}`  
**Action:** `PlaceOrderAction::confirm`

```
💬 {карточка рецепта — editMessageReplyMarkup}
    (текст остаётся, меняется только клавиатура)

[🔙 К поиску]  [📋 Мои заказы]
```

> Toast-уведомление: «Заказ отправлен! 🍸»

### Ошибка — нет активной сессии

> Toast-уведомление: «🚫 Нет активной сессии» (без смены клавиатуры)

## 11. Уведомление бармену (push)

**Когда:** при создании заказа гостем, `PlaceOrderAction::notifyManagers`  
**Получатель:** все пользователи с ролью bartender/owner

```
💬 🍹 *Новый заказ ×{qty}*

Коктейль: {recipe.name_ru}
Гость: {guest.first_name} (@{guest.username})

🔔 Кнопки «Принять» — по одной на количество от qty до 1:
  [✅ Все (×3)] [✅ ×2] [✅ ×1]   (если qty = 3)
  [✅ Все (×1)]                   (если qty = 1)
[❌ Отказать]
```

> Callback: `order:qty:{id}:{n}` и `order:cancel:{id}`.

## 14. Сессия

**Триггер:** `/session`, callback `cmd:session`  
**Action:** `SessionAction::fromTelegram`

### 14a. Сессия активна (любой пользователь)

```
💬 🍸 *Сессия открыта*
С {HH:MM}
Закроется в {HH:MM}
```

### 14b. Нет сессии — гость

```
💬 🍸 Сессия не открыта.
```

### 14c. Нет сессии — bartender/owner, бар открыт

```
💬 🍸 Бар работает. Открыть сессию?

[🟢 Старт]
```

### 14d. Нет сессии — bartender/owner, бар закрыт

```
💬 🍸 Бар закрыт. Работает с {workStart} до {workEnd}
(последний старт за {openCutoffMinutes} минут до закрытия).
```

### 14e. Нажата кнопка «🟢 Старт»

**Триггер:** callback `session:start` (только bartender/owner)  
**Action:** `StartSessionAction::fromTelegram`

> Toast-уведомление: «✅ Сессия открыта» (если успешно)  
> Toast-уведомление: «🚫 Бар закрыт» (если BarClosedException)

## 16. Список избранного (Phase 4)

**Триггер:** `/favorites`  
**Conversation:** `ListFavoritesConversation`

### 16a. Список пуст

```
💬 У тебя пока нет избранных рецептов 🤍

(без клавиатуры)
```

### 16b. Непустой список

```
💬 (моноширинный блок)
```
 1. Маргарита            ⭐4.2 24% 120мл
 2. Негрони                   24%  75мл
 3. Лонг Айлендский ча… ⭐3.8 18% 500мл
```

Введи номер для просмотра:

[<<][🏠 Главная][>>]
```

> Клавиатура: `<<` и `>>` — кнопки навигации по страницам (disabled = noop на границах).
> Каждая страница — до 10 рецептов.
> Смешанный ввод: нажатие кнопок `<<`/`>>` (callback) и ввод числа 1–10 (text) обрабатываются в одном шаге `handleInput`.
