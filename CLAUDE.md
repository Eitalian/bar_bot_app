## Политика обновления

**Методология проекта живёт в `AGENTS.md`** — он импортируется директивой `@AGENTS.md` выше и подгружается в контекст вместе с этим файлом. `AGENTS.md` одновременно читают и другие AI-инструменты (Codex, Cursor), поэтому источник правды один.

**Куда вносить правки:**

| Что меняется | Файл |
|---|---|
| Команды, архитектура, конвенции миграций, git workflow, агентский процесс, стиль ответов, planned features | `AGENTS.md` |
| Claude-Code-специфика: skills config, hooks, slash-команды, settings.json-нюансы | `CLAUDE.md` (этот файл, ниже) |
| Долгоживущие архитектурные контракты | `.agents/specs/` |
| Дизайн конкретной фазы/фичи | `.agents/designs/` |
| План реализации фазы | `.agents/plans/` (по шаблону `_template.md`) |
| Карта кодобазы, статусы фаз, паттерны с примерами | `.agents/knowledge/codebase.md` |

**Не дублировать `AGENTS.md` в `CLAUDE.md`.** Если правка применима к любому агенту — она идёт в `AGENTS.md`. Этот файл остаётся тонким: import + Claude-Code-only надстройки.
